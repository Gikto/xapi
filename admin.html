Préparation

Stock

Pour chaque miel, trois choix : Disponible (le site ne dit rien, c'est le réglage normal), Épuisé (le site affiche « Épuisé » et refuse la commande), ou Nombre exact si vous voulez compter vos pots : le site affiche « Plus que N pots » sous 5, puis « Épuisé » à zéro. Une commande annulée remet ses pots en stock.

Miels

Ici vous gérez les miels proposés sur le site : nom, texte, caractéristiques, photos. Pour une nouvelle récolte, ajoutez un miel (ou modifiez le nom d'un existant). Un miel masqué disparaît du site mais garde son historique. Les prix se règlent dans Réglages, le stock dans Stock. N'oubliez pas d'enregistrer en bas.

Aide

Une commande arrive

Vous recevez un e-mail. Le client reçoit les détails du virement. Quand l'argent est sur le compte, ouvrez Commandes et appuyez sur Marquer payé. À la remise du pot, appuyez sur Marquer retiré.

Préparer les pots

Préparation liste tout ce qu'il faut sortir, y compris les commandes pas encore payées (marquées « PAS ENCORE PAYÉ » : on ne les remet qu'après paiement). Le bouton Imprimer donne une feuille.

Rupture de miel

Dans Stock, choisissez Épuisé pour le format concerné. Pour le remettre en vente, rechoisissez Disponible.

Une nouvelle récolte

Dans Miels : + Ajouter un miel, écrivez le nom et le texte, ajoutez les photos des pots (touchez le cadre photo), puis Enregistrer. Le miel apparaît tout de suite sur le site. Pensez ensuite à régler son stock.

Faire une pause

Vacances ou rupture totale : dans Réglages → Suspendre les commandes, cochez la case et écrivez un message. Les clients ne peuvent plus commander. Décochez pour rouvrir.

Afficher une annonce

Dans Réglages → Bandeau d'annonce, écrivez une phrase : elle s'affiche en haut du site sans bloquer les commandes. Enregistrer un champ vide (ou « Retirer le bandeau ») la supprime.

Sauvegardes

Le 1er de chaque mois, un fichier avec toutes les commandes arrive par e-mail. Conservez-le.

Mot de passe oublié

Sur la page de connexion, touchez « Mot de passe oublié ? ». Un code arrive par e-mail à l'adresse d'alerte.

Le site ne répond plus

Contactez Jonathan. S'il s'agit d'une pause de la base de données (rare : un contrôle automatique l'évite), elle se réactive en quelques minutes depuis le compte Supabase.

Un avertissement rouge sur le tableau de bord

« Des e-mails n'ont pas pu partir » : les clients ou vous n'avez peut-être pas reçu certains messages. Prévenez Jonathan (le plus souvent, une clé d'envoi à renouveler), puis appuyez sur « J'ai compris ». Un client sans e-mail : vérifiez-le dans Commandes.

Lieux de retrait

Ces lieux sont proposés dans le formulaire de commande. Décocher « Actif » masque un lieu sans toucher aux anciennes commandes. Le texte de la page « Où nous trouver » se modifie séparément.
